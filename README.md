# Wondr

Assistant IA personnel pour Termux, utilisant l'API Gemini.

## Installation

```bash
git clone https://github.com/archemisai-lab/Wondr.git ~/wondr
cd ~/wondr
bash install.sh
```

L'installateur demande une clé API Gemini si aucun fichier `.env`
n'existe, installe les dépendances et configure la commande `wondr`.

## Utilisation

```bash
wondr
```

La clé API reste dans le fichier local `.env`.
Ne publiez jamais ce fichier.
